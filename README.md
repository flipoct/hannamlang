# 한남랭 (HannamLang)

한남말투로 쓰는 난해한 프로그래밍 언어(esolang)와 브라우저 에디터.

**바로 써보기: https://hannamlang.vercel.app**

## 문법

명령은 공백으로 구분한다. 변수는 1번부터 있고 초깃값은 0이다.

| 명령 | 하는 일 |
|---|---|
| `엄.` | 마침표 n개면 n번 변수를 쓴다. `엄...`은 3번. 안 쓰면 1번 |
| `아뇨` | 아뇨 n개면, n번 변수가 0이 아닐 때 반복문에 들어간다. 0이면 짝이 맞는 끝 뒤로 건너뜀 |
| `줴줴이야` | 반복문 끝. 짝이 맞는 아뇨로 돌아가서 다시 검사 |
| `예?` | 정수를 입력받아 현재 변수에 넣는다 |
| `요이~~` | 뒤 물결 m개면 현재 변수에 m을 더한다. `요이`는 1 |
| `요~~이` | 가운데 물결 n개면 현재 변수에 n번 변수를 더한다 |
| `요~~이~~~` | 둘 다 있으면 n번 변수 + m을 더한다 |
| `쥐랄` | 빼기. 물결 규칙은 `요이`와 같다. `지랄`도 똑같이 먹힌다 |
| `티~원` | 현재 변수를 문자로 출력 (유니코드라 한글도 됨) |
| `T~1` | 현재 변수를 숫자로 출력 |
| `아` | 아무 뜻 없는 꾸밈. `아 줴줴이야`, `아예?`처럼 아무 데나 |

그 밖의 단어는 무시되므로 주석처럼 쓸 수 있다.

## 예제: 두 수 더하기

```
엄. 아 예?
엄.. 아 예?
엄. 요~~이
T~1
```

에디터의 예제 메뉴에 곱하기, 카운트다운, 피보나치, 소수 판정, 헬로 월드 등이 더 있다.

## 에디터 기능

- 문법 색칠, 오류 위치 표시, 커서 위치 명령 풀이
- 실행 / 한 단계 / 속도 조절, 실행 중인 명령 표시
- 변수 값 보기, 입력이 모자라면 실행 중에 물어봄
- 문장 → 코드 생성기, 링크로 공유, `.hnl` 파일 저장/열기

## 로컬에서 실행

빌드 없음. 정적 파일 두 개(`index.html`, `hannamlang.js`)뿐이라 아무 정적 서버로 열면 된다.

```
python -m http.server 8147
```

`hannamlang.js`는 node에서도 쓸 수 있다.

```js
const H = require('./hannamlang.js');
H.run('엄. 아 예? 엄.. 아 예? 엄. 요~~이 T~1', [3, 4]).out; // '7'
```
